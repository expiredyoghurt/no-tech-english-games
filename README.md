# No Tech English Games

Cloudflare Pages project: `no-tech-english-games`

English Games Hub — 20 classroom English games and supporting play tools for P5/P6.

## Deployment

This is a static HTML project. There is no framework and no build step.

Recommended Cloudflare Pages settings:

- Production branch: `main` (if deploying from Git)
- Build command: `exit 0`
- Build output directory: `.`
- Functions: none required

The site entry point is `index.html`.

## Notes

- The application is client-side JavaScript.
- No server-side code is required.
